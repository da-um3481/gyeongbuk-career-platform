2원스톱 등록 순서 (8단계)

순서의 원칙: 기관 → 기준자료 → 학생 → 일정 → 자료 → 기록 → 진단 → 리포트. 앞 단계가 비어 있으면 뒤 단계에서 학생을 고를 수 없습니다.

  1. 기관 등록 — 「기관·대상 관리」 학교·센터·개인 컨설팅 대상을 등록합니다. 기관명, 유형(학교/지자체 센터/개인), 지역, 담당자 연락처, 프로그램명, 기수, 운영기간, 정원을 입력합니다.
    • 학생을 먼저 기관에 묶어두면 이후 리포트·자료실에서 기관 단위로 묶어 볼 수 있습니다.
  2. 기준자료 확인 — 「운영 데이터 입력 센터」 CSV 등록은 이미 등록된 이름과 정확히 일치해야 통과합니다. 지금 등록된 기준자료는 아래와 같습니다.
    구분등록된 값
    과목 (5)국어 · 수학 · 영어 · 과학 · 사회
    단원 (8)수학: 이차함수 · 이차방정식 · 다항식의 곱셈과 인수분해 · 실수와 그 계산

  3. 학생 등록 — 「CSV 일괄 등록」 (권장) 또는 「운영 데이터 입력 센터」
    • 여러 명 한 번에: 등록 대상에서 학생 명단 선택 → CSV 파일 업로드 또는 붙여넣기 → 미리보기에서 검증 결과 확인 → 등록. 최대 500행.
    • 필수 열: 학생코드, 이름 / 선택: 학년, 학교, 학부모명, 학부모연락처, 학부모이메일, 학습목표
    • 한 명씩 등록하거나 수정·삭제할 때는 「운영 데이터 입력 센터」의 학생 탭을 씁니다(입학일·학습스타일·메모까지 입력 가능).
    • 이미 있는 학생코드는 자동으로 건너뜁니다(중복 등록 사고 없음).
  4. 수업 일정 등록 — 「CSV 일괄 등록」(등록 대상: 수업 일정)
    • 필수 열: 날짜 / 선택: 시작시간, 종료시간, 학생코드, 과목, 주제, 담당교사, 강의실, 상태, 출결
    • 학생코드나 과목명이 등록된 값과 다르면 그 행만 건너뜁니다(미리보기에서 표시).
    • 등록 후 「수업 캘린더」에서 월간으로 확인하고, 개별 수업은 「운영 데이터 입력 센터」에서 수정합니다.
  5. 학습자료 등록 — 「학습 콘텐츠·교재 관리」, 「문제뱅크 관리」
    • 교재·강의영상·문제집을 등록하고 학생에게 배정합니다(배정 이력 관리).
    • 문제뱅크에 단원·난이도·문항을 등록해 두면 「시험지 자동 출제」로 바로 뽑을 수 있습니다.
  6. 일상 기록 — 매일/매주 쓰는 화면
    화면무엇을 기록하나요
    숙제 배부·제출 확인숙제 배부, 제출 여부·점수·기한 처리
    운영 데이터 입력 센터AI 튜터 세션, 평가 결과, 학습 진도, 학부모 리포트 (각 항목 추가·수정·삭제)
    공부코치일일 학습 계획, 실제 학습시간, 집중도
    출결·AI세션 트래커기록된 출결·세션을 한눈에 확인(조회)
  7. 진단·처방 — 「검사 진단·해석」부터
    • 검사 결과 일괄 업로드: CSV 또는 엑셀(xlsx) 파일의 첫 시트. 필수 열 학생코드 · 검사종류(MLST2/MCDT/NEO) · 검사일(2026-10-12) · 척도코드 · 점수 (선택: 검사명). 학생코드와 척도코드가 등록돼 있어야 통과합니다.
    • 내신 성적은 「내신등급 계산기」에서 과목별 석차·이수자수를 넣으면 5등급제 기준 등급이 계산됩니다.
    • 목표 대학·전형은 「대입 로드맵」에 등록하고, 로드맵 단계는 단계별로 추가·완료 처리합니다.
    • 취약 단원이 잡히면 「취약 단원 진단·처방」에서 학습경로를 자동 생성 → 「맞춤 학습경로 편집」에서 순서를 조정 → 「학습 처방 자료실」에서 자료를 붙입니다.
  8. 리포트·상담 — 마무리 단계
    • 「학부모 리포트 생성기」에서 학생을 고르면 진도·출결·평가·세션 기록이 자동으로 모여 리포트 초안이 만들어집니다 → 검토 후 저장.
    • 「통합 진단 리포트」는 검사·내신·목표·취약 단원을 한 장으로 묶어 상담 자료로 씁니다.
    • 상담 내용은 「진학·학습 상담 기록」에 남깁니다.

6아직 없는 기능 (실사용 시 참고)

  • 과목·단원·평가 추가 화면 없음 — 현재 등록된 값 안에서만 선택·매칭됩니다. 필요하면 기준자료 등록 수단을 만들어 드립니다.
  • 검사 척도(MLST-2 · MCDT · NEO) 추가 화면 없음 — 표준 척도 77개가 미리 들어 있습니다.
  • 계정·권한 구분 없음 — 워크스페이스에 접근할 수 있는 사람은 모두 입력·수정할 수 있습니다. 외부 공유는 하지 않는 것이 안전합니다.
  • 학부모 리포트의 '발송'은 발송 상태 기록입니다. 실제 메일 발송은 별도로 진행합니다.
  • 오프라인 파일은 입력 불가 — 조회·인쇄(브라우저 인쇄로 PDF 저장) 전용입니다.
